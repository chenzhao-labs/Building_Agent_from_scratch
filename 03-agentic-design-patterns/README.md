# AI Agent性设计原则

## 介绍

有许多方法可以思考构建 AI Agent系统。鉴于在生成式 AI 设计中，模糊性是特性而非缺陷，工程师有时很难确定从何开始。我们创建了一套以人为中心的用户体验设计原则，以帮助开发者构建以客户为中心的Agent系统来解决其业务需求。这些设计原则并不是规范性的架构，而是为正在定义和构建Agent体验的团队提供的起点。

一般而言，Agent应当：

- 扩展和放大人类的能力（头脑风暴、解决问题、自动化等）
- 弥补知识空白（让我在知识领域中快速上手、翻译等）
- 促进并支持以我们个人偏好的方式与他人协作
- 使我们成为更好的自己（例如，生活教练/任务管理者，帮助我们学习情绪调节和正念技能，增强韧性等）

## Agent性设计原则

![Agentic Design Principles](../../../translated_images/zh-CN/agentic-design-principles.1cfdf8b6d3cc73c2.webp)

### Agent (Space)

这是Agent运行的环境。这些原则为我们在物理和数字世界中设计Agent的方式提供指导。

- **连接，而不是替代** – 帮助将人们与其他人、事件和可操作的知识连接起来，以促进协作与联系。
- Agent帮助连接事件、知识和人。
- Agent将人们拉得更近。它们不旨在取代或贬低人。
- **易于访问但有时隐形** – Agent在后台运行，仅在相关且合适时提醒我们。
  - 经过授权的用户可以在任何设备或平台上轻松发现并访问Agent。
  - Agent支持多模态输入与输出（声音、语音、文本等）。
  - Agent可以根据对用户需求的感知，在前台和后台之间、在主动与被动之间无缝切换。
  - Agent可能以隐形形式运行，但其后台处理路径及与其他Agent的协作对用户是透明且可控的。

### Agent (Time)

这是Agent随时间运行的方式。这些原则为我们设计在过去、现在和未来交互的Agent提供指导。

- **过去**：反思包括状态和上下文的历史。
  - Agent基于对更丰富历史数据的分析（不仅仅是事件、人物或状态）提供更相关的结果。
  - Agent从过去事件创建连接，并主动反思记忆以应对当前情境。
- **现在**：更多的是引导而不是单纯通知。
  - Agent体现了与人互动的全面方法。当事件发生时，Agent不仅仅是静态通知或其他形式的形式化。Agent可以简化流程或动态生成提示，以在恰当的时刻引导用户的注意力。
  - Agent根据上下文环境、社会和文化变化以及用户意图来提供信息。
  - Agent交互可以是渐进的，随着时间推移逐步演变/变得更复杂，以在长期内赋能用户。
- **未来**：适应与演进。
  - Agent适应各种设备、平台和模态。
  - Agent适应用户行为、无障碍需求，并且可以自由自定义。
  - Agent通过持续的用户交互得到塑造并不断演进。

### Agent (Core)

这些是Agent设计核心中的关键要素。

- **接受不确定性但建立信任**。
  - 预计Agent会存在一定程度的不确定性。不确定性是Agent设计的关键要素。
  - 信任与透明是Agent设计的基础层。
  - 人类可以控制Agent何时开启/关闭，且Agent状态在任何时候都应清晰可见。

## 实施这些原则的指南

在使用上述设计原则时，请使用以下指南：

1. **透明性**：告知用户 AI 的参与方式、其如何运作（包括过去的行为），以及如何提供反馈和修改系统。
2. **控制权**：使用户能够自定义、指定偏好和个性化，并对系统及其属性（包括“忘记”能力）拥有控制权。
3. **一致性**：在设备和端点之间追求一致的多模态体验。在可能的情况下使用熟悉的 UI/UX 元素（例如用于语音交互的麦克风图标），并尽量降低客户的认知负担（例如，追求简洁响应、视觉辅助和“了解更多”内容）。

## 如何使用这些原则和指南设计一个旅行Agent

假设您正在设计一个旅行Agent，下面是您如何考虑使用这些设计原则和指南的方式：

1. **透明性** – 让用户知道旅行Agent是一个启用 AI 的Agent。提供一些基本的入门说明（例如，“你好”消息、示例提示）。在产品页面上清楚记录这些内容。显示用户过去询问的提示列表。明确说明如何提供反馈（点赞和点踩、发送反馈按钮等）。明确说明Agent是否有使用或主题限制。
2. **控制权** – 确保清楚说明用户在创建Agent后如何通过诸如系统提示之类的方式对Agent进行修改。使用户能够选择Agent的详细程度、写作风格，以及Agent不应讨论的任何注意事项。允许用户查看并删除任何相关文件或数据、提示和过往对话。
3. **一致性** – 确保“共享提示”、“添加文件或照片”和“标注某人或某物”的图标是标准且易识别的。使用回形针图标表示与Agent的文件上传/共享，使用图片图标表示图像上传。
